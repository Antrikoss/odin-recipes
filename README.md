# odin-recipes
The Odin Project - Project: Recipes

## Introduction
This project was about creating a recipes website. It contains a 
home page and 3 recipe pages. Each recipe page contains an image of 
the finished dish, a description, an ingredients list, and the list 
of steps.

## Skills I learned
- What is the "HTML boilerplate"
- How to structure a website with multiple pages
- How to link pages together
- How to add images with *absolute links*
- How to add headings (h1 and h3)
- How to add paragraphs
- How to create an ordered and unordered list of items
- How to publish web projects directly from GitHub if I have created a public repo
- How the Git workflow works:
    - How to make commits
    - What and why to commit
    - How to write meaningful commit messages
    - How to push changes to remote GitHub repo
